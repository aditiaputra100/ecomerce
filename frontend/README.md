# Frontend (React + Vite)

Single-page storefront & seller dashboard built with React, TypeScript, React Router, Material UI, and Zustand. It consumes the FastAPI backend for authentication, shop management, product inventory, carts, checkout, and Midtrans Snap payments.

## ✨ Features

- **Auth & persistence** – register/login, token storage, and bootstrap that fetches the current user + shop info on refresh.
- **Buyer journey** – catalog grid, product detail, cart management, checkout screen, Midtrans Snap hand-off, and status page.
- **Seller workflow** – guided “Open Store” form, dashboard overview, product CRUD with image upload, and order fulfillment controls.
- **Shared UI** – themed layout, protected routes based on ownership, reusable API client + hooks.

## ⚙️ Environment Variables

Create `frontend/.env` (or `.env.local`) with:

```
VITE_API_URL=http://localhost:8000
VITE_MIDTRANS_SNAP_URL=https://app.sandbox.midtrans.com/snap/snap.js
```

`VITE_API_URL` should match the backend base URL, while `VITE_MIDTRANS_SNAP_URL` can point to production when you flip the backend to production mode.

## 🛠️ Development

```bash
cd frontend
npm install
npm run dev
```

Visit `http://localhost:5173`. The dev server proxies API calls directly to the backend URL configured above, so ensure the FastAPI app is running first.

## 📦 Production build

```bash
npm run build    # type-check + Vite build
npm run preview  # optional smoke test of the build
```

Deploy the `dist/` folder behind your preferred static host.

## 🔄 Midtrans flow

The frontend requests the Midtrans client key from `/payments/config`, loads the Snap script dynamically, and calls `window.snap.pay` with the token generated by the backend when an order is created. Success, pending, and error callbacks redirect to `/checkout/status`, which reads Midtrans redirect query params and surfaces the final state.
